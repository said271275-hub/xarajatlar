# Xarajatlar hisobi 💰

Daromad va xarajatlarni kuzatish uchun React + Tailwind CSS ilovasi.

## Imkoniyatlar
- Daromad va xarajat qo'shish (summa, toifa, sana, izoh)
- Oylar bo'yicha filtr
- Umumiy hisob: daromad, xarajat, qoldiq
- Xarajatlar toifalar bo'yicha doira diagramma (SVG, kutubxonasiz)
- Kunlar bo'yicha guruhlangan yozuvlar ro'yxati, o'chirish
- Ma'lumotlar `localStorage` da saqlanadi
- Neumorphism (soft UI) dizayni, telefon va kompyuter uchun moslashuvchan

## Texnologiyalar
React 18, Vite, Tailwind CSS v4

## Ishga tushirish
```bash
npm install
npm run dev
```
